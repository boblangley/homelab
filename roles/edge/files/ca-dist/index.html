Trust our home network

Our home has its own private websites, like home.internal (the family dashboard). Your phone or computer will show scary security warnings on them until you install our home's security certificate, a small file that tells your device "these sites are ours, they're safe".

You only do this once per device. It takes about two minutes. Your device must be on the home Wi-Fi.

Your browser may say "Not secure" on this page. That is expected. This page is how you fix that.

Pick your device:

iPhone / iPad

On a computer? Point your iPhone's camera at this code and tap the link that pops up.

  1. Download it. In Safari, tap this link. When it asks, tap Allow, then Close.
    It must be Safari for this step. If the link opened in Chrome, Brave, Opera, Vivaldi or another app, copy it into Safari.
  2. Install it. Open the Settings app. Near the top, tap Profile Downloaded. Tap Install, enter your passcode, then tap Install twice more and Done.
    Don't see "Profile Downloaded"? Go to General → VPN & Device Management.
  3. Turn it on. Don't skip this! In Settings, go to General → About, scroll all the way down, tap Certificate Trust Settings, switch on Homelab Root CA and tap Continue.

Done! Now check it worked. After this, every browser on the iPhone or iPad trusts our sites: Safari, Chrome, Brave, Opera, Vivaldi and the rest.

Android phone

On a computer? Point your phone's camera at this code and tap the link that pops up.

  1. Download it. Tap this link. The file saves to your Downloads.
    If your phone says it can't install it from here, that's normal. Carry on.
  2. Install it. Open the Settings app and search for CA certificate. Tap it, then Install anyway, and unlock your phone if asked.
    No search? Try Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate. Every phone brand words this a bit differently.
  3. Pick the file called homelab-root.crt from your Downloads.

Your phone may now show a message like "Network may be monitored". That is a standard notice for any installed certificate; nothing is watching you.

Chrome, Samsung Internet, Brave, Opera and Vivaldi trust our sites straight away.

Done! Now check it worked.

Using Firefox on Android?

Open Firefox → Settings → About Firefox, tap the Firefox logo 5 times, go back to Settings → Secret Settings and turn on Use third party CA certificates.

Other apps (not browsers) may still not trust our sites. That is an Android limit.

Windows PC

You need to be able to approve "Do you want to allow this app to make changes" prompts.

  1. Download it. Click Download certificate
  2. Open it. Open your Downloads and double-click homelab-root.crt. Click Open if asked, then Install Certificate…
  3. Choose Local Machine and click Next. Click Yes on the prompt.
  4. Choose Place all certificates in the following store, click Browse…, pick Trusted Root Certification Authorities, click OK, then Next and Finish.
  5. You should see "The import was successful."

Done! Close your browser completely, open it again, and check it worked. Edge, Chrome, Brave, Opera and Vivaldi use this straight away. Using Firefox or Zen? See this note.

For the technically minded: PowerShell

As administrator:

Invoke-WebRequest http://ca.internal/homelab-root.crt -OutFile $env:TEMP\homelab-root.crt
Import-Certificate -FilePath $env:TEMP\homelab-root.crt -CertStoreLocation Cert:\LocalMachine\Root

Mac

  1. Download it. Click Download certificate
  2. Open it. Open your Downloads and double-click homelab-root.crt. The Keychain Access app opens (enter your Mac password if asked).
  3. In Keychain Access, find Homelab Root CA in the list and double-click it.
  4. Click the little arrow next to Trust. Change When using this certificate to Always Trust.
  5. Close that window and enter your Mac password to save.

Done! Quit your browser completely, open it again, and check it worked. Safari, Chrome, Brave, Opera and Vivaldi use this straight away. Using Firefox or Zen? See this note.

For the technically minded: Terminal

Installs for all users on the Mac:

curl -fsSLo ~/Downloads/homelab-root.crt http://ca.internal/homelab-root.crt
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain ~/Downloads/homelab-root.crt

CachyOS / Arch Linux

Run in a terminal:

curl -fsSLo /tmp/homelab-root.crt http://ca.internal/homelab-root.crt
sudo trust anchor --store /tmp/homelab-root.crt

Restart your browser. Firefox, Zen, Chrome/Chromium, Brave, Opera, Vivaldi and command-line tools all use the system store. If Zen or Firefox still warns, see this note.

Check, verify or remove

Check it is installed:

trust list --filter=ca-anchors | grep -A2 "Homelab Root CA"

Verify the file before trusting it (compare with the fingerprint at the bottom of the page):

openssl x509 -in /tmp/homelab-root.crt -noout -fingerprint -sha256

Remove later:

sudo trust anchor --remove /tmp/homelab-root.crt

Ubuntu / Debian / Raspberry Pi OS

Run in a terminal (the last command should say "1 added"):

sudo curl -fsSLo /usr/local/share/ca-certificates/homelab-root.crt http://ca.internal/homelab-root.crt
sudo update-ca-certificates

That covers command-line tools. Browsers keep their own list:

  • Firefox or Zen (the Ubuntu Firefox snap ignores the system store): see this note.
  • Chrome, Chromium, Brave, Opera or Vivaldi (they share one list), if they still warn after a restart:
sudo apt install libnss3-tools
certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "Homelab Root CA" -i /usr/local/share/ca-certificates/homelab-root.crt
Verify or remove

Verify the file (compare with the fingerprint at the bottom of the page):

openssl x509 -in /usr/local/share/ca-certificates/homelab-root.crt -noout -fingerprint -sha256

Remove later:

sudo rm /usr/local/share/ca-certificates/homelab-root.crt && sudo update-ca-certificates --fresh

Did it work?

Open https://home.internal. If it opens without a warning, you're all set.

Still see a warning? Close the browser completely and try again. On a phone, check you did every step, especially the last one on iPhone. On a computer with Firefox or Zen, see the note below.

Using Firefox or Zen on a computer?

Firefox and Zen (which is built on Firefox) sometimes keep their own list. If yours still warns after the steps above:

  1. Open the browser's Settings and search for certificates. Click View Certificates…
  2. Go to the Authorities tab, click Import… and pick homelab-root.crt from your Downloads.
  3. Tick Trust this CA to identify websites and click OK.
